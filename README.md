## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/990prem/TypeScript.git
```

Go to the project folder:

```bash
cd TypeScript
```

Compile a TypeScript file:

```bash
tsc filename.ts
```

Run the generated JavaScript file:

```bash
node filename.js
```
